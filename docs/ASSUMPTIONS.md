## MCP

Key finding: spec **2026-07-28** is a large revision. It removes the connection handshake and session, removes server-initiated requests (replaced by multi-round-trip requests, MRTR), deprecates roots, sampling and protocol logging, removes `ping`, and replaces resource subscriptions with one `subscriptions/listen` stream. Tasks became an **extension** (`io.modelcontextprotocol/tasks`), negotiated per request. SDK v2 can serve legacy (pre-2026) clients.
