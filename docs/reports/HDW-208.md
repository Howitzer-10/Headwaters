## Summary
Added an end-to-end MCP suite that drives the eight front-door tools through the in-process SDK client (real engine, scripted local backend, no network), and a host-eval harness skeleton in `bench/host_eval/`. The harness runs 10 scripted tasks for each (host profile, dispatcher) pair against the real server and scores tool selection, argument validity and relay compliance, writing JSON and Markdown reports. Only mock dispatchers ship; real models and the 100+ task suite are HDW-705.
