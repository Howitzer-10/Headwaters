## Summary
A local (Ollama) call whose messages contain an `image_url` that is not a `data:...;base64,` URL now raises a structured `image_url_not_local` error instead of silently dropping the image (review F17). The check runs while the payload is built, so no HTTP call is made and nothing is fetched. Data URLs are still inlined and sent.
