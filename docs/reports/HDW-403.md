## Summary
`headwaters install|uninstall --host <id>|all` now puts Headwaters into a host: one generic engine
plans every file change, prints a unified diff, asks for consent, backs the original up, writes,
reads the file back and verifies it, and can restore it later. Four adapters cover VS Code /
Copilot Chat (MCP entry, BYOK custom endpoint with tool calling, `chat.agentHost.byokModels.enabled`,
prompt files and the instructions pack), Cline, OpenCode (provider `baseURL` plus MCP) and Claude
Desktop (MCP only). The five carried follow-ups are closed with code and tests rather than notes:
the launcher path is checked before a config is written (FU-202-5), the OpenCode provider has a real
shared id so the switch command in `recommend.py` is exact (FU-205-3), each host's command folder,
argument convention, rules file and front matter was checked against the current official docs
before the files are generated (FU-207-1, FU-207-2), and `headwaters doctor` now reads each host's
own config and warns when it drifts (FU-402-2).

## Files changed

- headwaters/installer/jsonc.py: new; a JSON-with-comments parser and a stable 2-space writer, so a host file that a user commented still parses and comes back unchanged.
