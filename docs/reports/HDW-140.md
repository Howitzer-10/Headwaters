## Summary
Core hooks for `headwaters_think` (D12). `RouteRequest.task_hint` forces `soft.task` without touching the hard filter. `RouteRequest.reasoning` fills `ExecOptions.reasoning` and, when on, adds `HardRequirements.reasoning`, a hard filter on the new `ModelRow.reasoning_ok` capability (Ollama `capabilities: thinking`, OpenRouter `supported_parameters: reasoning`, migration 3). The router now removes reasoning text from every result, stream event, row and ledger event.
