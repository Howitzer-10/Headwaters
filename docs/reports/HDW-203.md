## Summary
Added the core building blocks for files-by-path: workspace root selection (configured root is the
boundary, host roots may only narrow it, cwd fallback), path validation (traversal, drive letters,
UNC, device paths, Windows reserved names and streams, case-insensitive containment, symlink and
junction escape), ignore rules (`.gitignore`, `.headwatersignore`, catalog default secret/env
patterns that user negations cannot undo) and a simple token-budget packer that a `ContextPlugin`
can later replace. No MCP tool uses it yet (tools arrive with HDW-204 onward).

## Deviations
- The packet says "MCP roots → configured root → cwd". D9 (binding) says host roots may only narrow a configured root, so the order is: host roots inside the configured root, else configured root, else valid host roots, else cwd.
- Default secret/env patterns live in the catalog (`default_ignore_patterns`), not in code, to follow the "no hard-coded patterns" rule. This adds a catalog schema field.
- Symlink tests skip on this machine because symlinks cannot be created without privilege; the junction test and the pure-path tests still run on Windows. They run on Linux CI.
