## Summary
Session stickiness is now separate from residency (D11, F15). The session's last successful model gets a small `session_bonus` (rules, any tier) and leads the ladder while it meets the floor; its warm bonus and eviction penalty are never rewritten. A model is pinned only on an `ok` answer, and a `verify_failed` answer clears the pin (F16). `text_of` is renamed `content_text` and documented as not the secret-scan path (FU-120-4).
