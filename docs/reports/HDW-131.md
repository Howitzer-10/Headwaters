## Summary
`Router`, `Executor` and `QuotaTracker` (and `build_engine`) now take a rules provider (`Callable[[], Rules]`) and read it per request, so `headwaters private on` or airplane mode reaches a running daemon without a restart (F12). `enforce_scope` re-checks `private_lock` and airplane itself. The daemon runs `RulesManager` and a new timer that calls `QuotaTracker.poll_key` for keys with a spent paid wall (FU-122-2, F22 daemon part), under the discovery blocking rule.

## Files changed
- headwaters/core/rules.py: `RulesProvider` type and `as_provider` (a fixed `Rules` or a provider).
- headwaters/core/router.py: takes `Rules | RulesProvider`; one reading per `_select` (kept on `_Selection.rules` so `plan` uses the same one), one per re-decision and per early log.
- headwaters/core/executor/executor.py: takes `Rules | RulesProvider`; one reading per call in `_prepare`, and for `keep_alive`.
- headwaters/core/executor/guard.py: `enforce_scope` refuses any non-local tier under `private_lock` (`LocalScopeViolation`), next to the existing airplane check.
- headwaters/core/quotas.py: `walls` may be a provider; `_walls` is read at each use.
- headwaters/core/key_poll.py (new): finds active `exhausted` walls on `key:<alias>:paid` / `provider:<p>:paid` and polls them; paid class only.
- headwaters/core/catalog/discovery.py: `_network_block` renamed `network_block` (public, same rule).
- headwaters/core/engine.py: `build_engine` accepts a provider and hands it to Router, Executor and QuotaTracker.
- headwaters/daemon/service.py: `rules_source`, `live_rules`, `key_poll_once`, `key_poll_interval`, new background task; status, refresh and keep-warm read the live rules.
- headwaters/daemon/runner.py: starts a `RulesManager` and passes `manager.current`; stops it on exit.
- tests/router_rig.py: optional `rules_source` argument.
- docs/ASSUMPTIONS.md: one row.
