## Summary
The stdio shim now asks inside its host: its daemon client declares elicitation when the host does,
and the daemon's spend and scope questions reach the host in both protocol eras (a callback for
handshake-era hosts, the daemon's input-required result handed back for 2026-07-28 hosts). A host
that cancels a call stops it on the daemon (the model call is cancelled), a new advanced tool
`headwaters_job_cancel` stops a background job and ends it `cancelled`, finished job rows are
deleted after `mcp.job_retention_days`, and a yes is bound to the question's model and cost, so a
changed plan asks again (FU-206-8).
