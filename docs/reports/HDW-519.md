## Summary

`tier` carried one word for two facts, so rows could not say "we sell this **and** you can use it
for free on the free plan" without lying about one of them. `ProviderEntry` now states
`charges_money` and `free_access` (`none | marked | all | plan`), one formatter turns the pair into
the only four sentences that exist, and `free_limits` rows became clauses with a metric, a window
and the scope that names the subject to count. No tier name was added, renamed or removed: `tier`
stays as the derivation fallback and the routing vocabulary, exactly as D19 requires, and
`router.py`, `policy/`, `scope.py` and `SCOPE_TIERS` were not touched.

## Deviations

1. **GitHub Models is not added** (packet deviation 1, confirmed by P7): the vendor states the
   playground, catalog, inference API and BYOK are retired, so a row would be a permanently failing
   endpoint. The `plan` value covers what its "PAT, 15 rpm, account-tier" description would have
   needed.
2. **Cloudflare Workers AI has no `providers` row** (packet deviation 2): its base URL contains the
   account id, which today's literal `base_url` cannot express, and P1/P4 could not verify a
   template. A `free_limits` row records the 10,000 neurons/day allowance so the fact is not lost;
   `test_cloudflare_base_url_vars_or_row_absent` asserts the row's absence and the allowance's
   presence.
3. **A fourth `free_access` value, `plan`** (packet deviation 3): without it Gemini, Groq, Cerebras,
   Cloudflare and Mistral would each have had to claim something false. `plan` routes like `all`
   today; the difference is honesty for the reader and the residual risk recorded above.
4. **`mistral` moves `none` → `plan`, owner-approved.** Its `free_notes` said a free mode exists
   while the row also said every model is paid. The behaviour change: mistral's discovered models
   now report `tier == "free_cloud"` and are offered without a key, so a paid-plan key can be billed
   in `free` scope. Test:
   `tests/test_hdw514_providers.py::test_mistral_free_plan_models_are_free_and_embeddings_are_skipped`.
   The packet's "flagged for owner sign-off" sentence is now history: the owner approved it and no
   `none` fallback was kept.
5. **OpenRouter/nvidia counting moves from per-model to per-key** (packet deviation 5): both rows are
   key-scoped in the vendor's own docs, so the two clauses are `scope: "key"` and one key's requests
   are counted once. The legacy `rpm`/`rpd` fields still resolve to model scope, so old rows and old
   counters keep working.
6. **Refinement: `ProviderInfo` keeps `tier`** as well as gaining `charges_money`/`free_access`/
   `access`. The packet says `ProviderInfo(name, key_required, entry.labels())`; two merged tests
   (`tests/test_hdw514_keys_cli.py`, `tests/test_hdw515_opencode.py`) and the router read `.tier`, so
   the pair is reported alongside it instead of replacing it. One formatter still owns the strings
   (`test_two_labels_come_from_one_function` scans the package).
7. **Refinement: `ProviderEntry.note`** was added (D4's unverified rows need a place to say which
   probe could not run), and empty means absent, so an un-migrated catalog is unaffected.
8. **Cohere's compatibility `/models` endpoint exists** (P1), which supersedes the packet's
   assumption that a native listing adapter is unavoidable.
