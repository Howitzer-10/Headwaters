## Summary
The gateway's three "keep working when the cloud does not" chains are now pinned by one scenario
suite that drives the real router and both existing fixtures: an exhausted paid key or a throttled
free tier cascades to the local model, and the local model still completes an agent tool loop
(tool call out, `role: tool` result back in). `tests/rebuild_support.py` grew a
`ProgrammableProvider` that scripts one list of `Delta`s or `ProviderError`s per call and a
`provider=` hook on `DaemonRig`, so a scenario is written as the sequence of answers the network
would give rather than as assertions about mocks. No production code changed: the walls, the
cascade, the ★ paid-scope gate, the tool pass-through and the OpenAI/Anthropic shapes already
worked, and the ticket's own note says the multi-wall chain only applies behind the flag, so the
flag-off default is asserted as its own regression test rather than re-routed.
