## Summary
Escalation (`EscalationPlugin`) and the new core verified retry (D10) now redecide only over candidates whose score for the request's task is above the failed model's, with `escalation=None` so the optimistic rung cannot fire again. The core retry runs once when `verify_required` and the check failed, with no plugin needed, counts in `max_attempts` and stays in scope. This fixes F10 and the HDW-123 below-floor local case (FU-123-1).
