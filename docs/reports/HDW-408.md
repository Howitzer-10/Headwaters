## Summary

Closes FU-303-1 from HDW-303: `POST /v1/messages/count_tokens` is now served on the same
guarded loopback app as `/v1/messages`. It is local arithmetic — the body goes through the same
`_json_body`/`_messages`/`_tools` helpers, the total comes from `Analyzer.estimate_tokens`, and
nothing routes, picks a model, calls a provider or touches the router, locks, walls or quotas, so
the answer arrives even when no model can serve anything. The response is Anthropic's
`MessageTokensCount`, `{"input_tokens": N}`, and a body the messages face refuses is a 400
`invalid_request_error` here too, never a 404. README, `docs/FUNCTIONAL_TESTS.md` check #12 and the
HDW-303 row in `docs/ASSUMPTIONS.md` no longer record the endpoint as unserved.

## Assumptions

- 2026-11-03 row in `docs/ASSUMPTIONS.md` (HDW-408, closing FU-303-1): the route is
  `POST /v1/messages/count_tokens` over the Messages request body (`model` in every documented
  example, `messages` required) and the answer is `MessageTokensCount` = `{"input_tokens": number}`,
  "the total number of tokens across the provided list of messages, system prompt, and tools"; the
  guide says the figure is an estimate, that base64 images are counted, and that server tools, the
  MCP connector and URL-source images are refused. `model` is ignored for counting, the number is
  `Analyzer.estimate_tokens` (prose 4 chars/token, fenced code and tool definitions 3.5, the image
  hint per image), and no tokenizer dependency is added.

## Deviations

- `headwaters/gateway/openai_routes.py` is not in the packet's file list; it is where
  `build_gateway_app` mounts every route, so the route cannot be served without it.
- The deferred items named before coding were kept deferred: server tools, the MCP connector and
  URL-source images are counted here instead of refused (FU-408-1), and `thinking`/`tool_choice`/
  `metadata`/`stop_sequences` add nothing to the count because the parsed body carries no prompt
  text from them.
- A body with no `model` is counted rather than refused, which is stricter than the documented body
  but cannot mislead a client: the count never depends on a model.
