## Summary
On the dev GPU the busy check counted Ollama's own model as another app (99% of VRAM held by others), so keep-warm would skip with `gpu_busy`. Ollama's runner is a `llama-server.exe` child under Ollama's install folder that the old name check missed, and `/api/ps` `size_vram` turned out to under-report. The check now recognises that runner by its path and, when per-process memory is hidden, subtracts the `/api/ps` figure. The live state now reads not busy. `nvidia-smi` output is captured in `docs/` and decoded per line.

- The finish sequence said HDW-137; the ticket is HDW-144, so this report and the commit use HDW-144.
- A probe that renamed copies of executables to get a non-ASCII GPU process made Bitdefender quarantine the uv Python (a false positive, restored; exclusions added by the owner). It is not repeated and is not part of the code.
