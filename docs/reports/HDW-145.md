## Summary
Ran the daemon, shim and tools against a real host (Claude Code 2.1.310) and a real Ollama (0.40.13, RTX 4080 Laptop 12 GB). The Windows rule behind FU-202-1 is now reproduced in a test: only a host whose Job Object kills on close and allows neither breakaway flag can reap the daemon, and Claude Code's job allows silent breakaway, so its daemon is safe. The real-model flow (`ask`, `do`, an async job with progress, `headwaters_more`, job status and result, `think`, keep-warm) works through the shim; result links do not survive a daemon restart (FU-204-6, confirmed). No product code changed. This ticket added `scripts/host_probe.py`, a stdlib probe a person registers in VS Code, Cursor or Claude Desktop to finish the GUI rows, and `-m live` tests for everything that can be repeated.

- tests/test_host_probe.py: new; 12 unit tests of the probe (raw JSON-RPC, no host).

- docs/ASSUMPTIONS.md: one row with every measurement, host version and date.
- docs/reports/HDW-145.md: this report.
