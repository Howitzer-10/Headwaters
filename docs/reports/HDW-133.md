## Summary
Two score terms now change rankings. `scoring.offload_penalty` (default 30) is subtracted when a
local candidate's `fit.status == "offload"` (F14). The complexity penalty is now model-dependent:
`complexity_penalty_per_level * (complexity - 1) * (100 - quality) / 100`, so weaker models lose
more on hard requests and a 100-quality model loses nothing (F19). The per-level default went from
3 to 10 so the scaled term stays meaningful.
